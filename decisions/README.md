# Архитектурные решения (ADR)

Каталог для Architecture Decision Records — записей о значимых архитектурных решениях проекта.

## Формат имени файла

```text
ADR-<номер>-<краткое-название>.md
```

Пример: `ADR-001-database.md`.

## Шаблон ADR

```markdown
# ADR-<номер>. <Название решения>

## Идентификатор
ART-XXX

## Тип артефакта
Решение

## Источник
ЛР №X

## Статус
Предложено / Принято / Отменено / Заменено ADR-XXX

## Контекст
[Какая задача требует решения.]

## Решение
[Что выбрано.]

## Альтернативы
- [Вариант 1]
- [Вариант 2]

## Последствия
- [Положительные]
- [Отрицательные]
```
