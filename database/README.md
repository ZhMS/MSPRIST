# База данных проекта

Каталог для описания схемы базы данных и тестового наполнения.

## Структура

```text
database/
├── migrations/   — файлы миграций схемы (NNN_<название>.sql)
└── seed/         — тестовые данные
```

## Связь с моделью данных

Схема создаётся по модели данных (артефакт ART-007, `diagrams/data/erd.png`,
описание в `docs/05-data-models/data-model.md`).

## Правила

1. Одна миграция — один файл и одно изменение схемы.
2. Файлы миграций применяются по возрастанию номера.
3. Тестовые данные не используются в производственной среде.
