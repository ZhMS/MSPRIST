# Автомат печати фото из ВКонтакте

## О проекте

[Краткое описание системы: автомат самообслуживания, который принимает фотографии из социальной сети ВКонтакте (со страницы пользователя, из сообщества или по ссылке), обрабатывает их и печатает на принтере; управление выполняется с телефона пользователя через веб-интерфейс. Система предназначена для посетителей публичных мест (торговые центры, кафе, фотозоны) и решает проблему быстрой печати фото без передачи файлов через посторонние устройства.]

## Проблема

[Описание текущей проблемы или неэффективного процесса: напечатать фото из ВКонтакте на обычном автомате сложно — нужно перекидывать файлы на флешку или чужой компьютер, что долго, небезопасно и неудобно; персональные фото остаются на чужих устройствах; оператор автомата не знает, какие фото и сколько будет напечатано.]

## Цель проекта

[Какой результат должна обеспечить система: пользователь за несколько минут со своего телефона выбирает фото из ВКонтакте, оплачивает и получает распечатку на автомате без использования флешек и сторонних устройств.]
