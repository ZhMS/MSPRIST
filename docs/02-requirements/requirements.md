# Реестр требований

## Идентификатор
ART-002

## Тип артефакта
Документ

## Источник
ЛР №1

## Назначение
Зафиксировать функциональные и нефункциональные требования к системе.

## Функциональные требования

| ID | Требование | Приоритет | Связанная проблема |
|---|---|---|---|
| FR-001 | [Система должна предоставлять авторизацию пользователя через ВКонтакте] | Высокий | [P-001] |
| FR-002 | [Система должна показывать альбомы и фото пользователя для выбора] | Высокий | [P-001] |
| FR-003 | [Система должна позволять выбрать формат и количество копий печати] | Высокий | [P-001] |
| FR-004 | [Система должна принимать оплату заказа с телефона пользователя] | Высокий | [P-001] |
| FR-005 | [Система должна передавать задание в очередь печати автомата] | Высокий | [P-001] |
| FR-006 | [Система должна хранить историю заказов пользователя] | Средний | [P-002] |
| FR-007 | [Система должна показывать владельцу автоматов статус автоматов и выручку] | Средний | [P-003] |

## Нефункциональные требования

| ID | Требование | Категория | Критерий |
|---|---|---|---|
| NFR-001 | [Выбор фото и оформление заказа не должны превышать 3 минут] | Производительность | [Время от входа до подтверждения заказа ≤ 3 минут] |
| NFR-002 | [Фото пользователя не должны храниться дольше, чем требуется для печати] | Безопасность | [Автоудаление фото из очереди не позднее [24] часов после печати] |
| NFR-003 | [Система должна оставаться доступной при пиковых нагрузках в вечерние часы] | Надёжность | [Доступность веб-интерфейса ≥ [99]% времени работы автомата] |
| NFR-004 | [Интерфейс с телефона должен работать на экране от [5] дюймов] | Удобство использования | [Все шаги заказа доступны без горизонтальной прокрутки] |
